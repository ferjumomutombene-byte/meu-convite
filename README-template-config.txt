===================================================
 CONVITE DIGITAL DE CASAMENTO (TEMPLATE)
===================================================

COMO EDITAR PARA UM NOVO CASAMENTO:
1. Abre o ficheiro 'config.js' com qualquer editor de texto.
2. Altera os nomes, datas, fotos, textos de RSVP e opções de presentes.
3. Para alterar as cores principais do site, abre o 'style.css' e altera as variáveis :root no topo do ficheiro (ex: --cor-primaria, --cor-secundaria).

FOTOS E MÚSICA:
- Coloca os ficheiros de imagem e áudio dentro da pasta 'assets/' (ex: assets/musica.mp3).
- Ou utiliza URLs diretas de imagens alojadas na internet.

COMO PUBLICAR GRATUITAMENTE:

A) GitHub Pages:
   1. Cria um repositório no GitHub e envia todos os ficheiros.
   2. Vai a Settings -> Pages -> Source: selecione "main branch".
   3. O teu link estará pronto em instantes.

B) Netlify:
   1. Acede a netlify.com
   2. Arrasta a pasta do projeto diretamente para a área de upload ("Sites").

C) Vercel:
   1. Acede a vercel.com
   2. Importa a pasta ou repositório do GitHub com 1-clique.
